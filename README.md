# shiftlink-
ShiftLink replaces the WhatsApp groups Egyptian private hospitals use to fill open shifts with a real marketplace. Hospitals post a shift with specialty, pay, and requirements. Verified doctors browse, filter, and apply in one tap. Hospitals review applicants and confirm instantly, and both sides rate each other afterward to build trust on the platform. Built with React + Vite, running on mock data so it's fully interactive with zero backend setup.
